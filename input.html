The form primitive — a bordered control (label · optional leading icon · value / placeholder · optional trailing affordance) sitting under a label row and above a helper or error line. Two variant axes — State × Type — resolve to 16 published variants, plus four component properties (placeholder text, caption toggle, mandatory toggle, leading-icon toggle). All fills, strokes, labels and icons bind to semantic tokens; this page reflects the component after the consistency pass below (label typography, mandatory-asterisk font, helper color, border bindings and icon fills all fixed in Figma on 2026-09-09).

Duplicate component still present. An older 5-variant Input (nodeId 39:576) carries the correct State axis (Default · Hover · Focus · Error · Disabled) but no Type. The current one (768:5264) added Type but replaced the interaction states with Completed/Active. Next pass: merge — keep the Type axis, restore the full State machine, delete the legacy set, then re-instance across every screen. Do not compose from either variant until the merge lands.

Accessibility

      

        
Render a native <input> / <textarea> / <select>. The label uses <label for="…">; the helper caption is connected with aria-describedby; the error line uses the same attribute and adds role="alert".

        
Mandatory is signalled by the visible asterisk and a machine-readable required / aria-required="true". Never rely on the asterisk alone.

        
Error binds aria-invalid="true", swaps the border to border/destructive (1.5px) and replaces the helper caption with the error text — never remove the caption region silently, or the field jumps.

        
Focus is keyboard-visible via focus/ring as a 2px halo on top of the accent/border stroke. Gap: no State=Focus variant in Figma — wire :focus-visible in code until it is added.

        
Leading icons are decorative (aria-hidden="true"). The Select caret is decorative too; the button that opens the menu owns the aria-expanded.

      


      
Usage rules

      

        
Map Type to Mantine exactly: Text Input→<TextInput>, Select→<Select>, Multiselect→<MultiSelect>, Input box→<Textarea>. Never build an input from a styled div.

        
Only one height ships in Figma today, and this component doc mirrors that — no Size axis. If a truly denser or larger input is needed, add it in Figma as a variant first, then document it here.

        
Label uses the Label text style (13/18, 500), helper uses Caption (12/16, 500) in text/secondary. Value is Body (14/22). Never restyle a Body to fake a label.

        
Error state carries a caption line — never rely on the red border alone. Clear the error on the next successful change; don't leave a stale message.

        
Reserve Mandatory for fields the submit will actually reject. A red asterisk on optional fields trains people to ignore it.

Changelog — consistency pass
applied to Input in Figma on 2026-09-09 · fixes across all 16 variants

      

        
Open
State axis is incomplete. Only Default · Active · Completed · Error exist; the older 5-variant set (39:576) had Hover · Focus · Disabled. Merge into one component set that keeps every state and the Type axis, then delete the legacy component.

        
Open
Sizes are missing. The component ships only at height 40 — off-scale (nearest tokens are 36 / 44). Add Size=sm/md/lg bound to size/control-sm/-md/-lg.

        
Open
Radius binds to radius/xs (4). Should be radius/sm (6) to match every other control — rebind after the state/size expansion so it isn't repeated 16× and then again per size.

        
Open
External library variables in the Input Wrapper. Padding and radius on the inner wrapper bind to a foreign library (variables prefixed 8756…) — swap for the local space/8, radius/xs when the sizes land.

        
Open
Property name typo. Place holder text should be Placeholder text. Rename after downstream code aliases have been updated so the swap doesn't silently break instances.

        
Open
No dedicated popover / options-list component in Figma. The dropdown shown here is composed from the design-system tokens; promote to a Select · Options component (or a shared Menu) and instance-swap it into the Select and Multiselect variants so the popover is not redrawn per screen.

      

      
These edits change the Input component's variant bindings in Figma (label typography, mandatory-asterisk font, helper colour, border and icon tokens) — no primitive or semantic values changed. The Open items each add or restructure variants, so they need a design review before landing.
