00 Overview

The design system as a contract

A machine-readable reference for the design system, extracted directly from Figma. It exists so a design-time agent (Claude in Figma) and a dev-time agent (Claude + Mantine) consume the same vocabulary — tokens, not pixels. Read the tables for coverage; read the contract blocks at the end of each section for the values an agent must respect.

162 color variables = 53 primitives + 109 semantic (light/dark). 34 dimension tokens = 13 spacing + 6 radius + 3 stroke + 12 size. 142 components across 14 component sets.

How to read this contract

Each section carries four things: a token reference table (name · value · recommended Mantine prop · usage), a short set of numbered usage rules, a do / don't pair, and a machine-readable contract block (<script type="application/json">) that a future Claude session parses to know what to reuse and what is forbidden. Coverage is what the agent may reuse; the forbidden array is what it must never do.
