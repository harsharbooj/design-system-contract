NavItem Figma name: Tab atom · 852:10111 · 3 variants

The clickable row inside a navigation list. One variant axis, Type (Default · Hover · Pressed), and three component properties: a label, a boolean that hides the icon, and an icon instance-swap. The Figma component set is called Tab atom. In code and on this page it's <NavItem>. It is the foundation of Left Side Navigation, which holds 447 of its 461 instances.

Naming
Pressed means "selected / current page", not a momentary press. The variant used to be called Selected and was renamed. It still has the active look (selected/bg fill, accent/border stroke, text/label), and all 150 of its instances are the current item in a rail. In code it maps to active / aria-current="page". There is no separate :active press look. See Open questions.

Accessibility

      

        
Render a real link (<a href> or a router Link) inside <nav aria-label="Main navigation">. Never use a div with a click handler.

        
Give the current item aria-current="page". The active look uses fill and a 1px border and a text colour change, so it doesn't rely on colour alone.

        
The icon is decorative, so mark it aria-hidden="true". The Icon boolean may hide the icon, but the label is always present.

        
Contrast (computed): text/secondary on bg/surface is 5.55:1 (Light) and 8.97:1 (Dark). On bg/hover it is 5.00 and 7.25. text/label on selected/bg is 9.61 and 12.07. All pass AA 4.5:1.

        
Gap: no Focus variant exists. Wire :focus-visible to focus/ring in code (borrowed from Button) until Figma adds one.

      


      
Usage rules

      

        
Do
    
          
  • Map Type=Pressed to active and aria-current="page"
    • 
          
  • Keep exactly one Pressed item per list
    • 
          
  • Leave hover to :hover. Don't pin Type=Hover in screens
    • 
          
  • Swap the icon through Instance, not by detaching
    • 
        

        
Don't
    
          
  • Use Pressed for a momentary click flash
    • 
          
  • Hide the label to make an icon-only item (not designed)
    • 
          
  • Instantiate the unused NavItem set (271:6610)
    • 
          
  • Hardcode #EAF4F0 instead of selected/bg
    •

Low

Low

Low
The Instance swap's preferred values list only folder. Add the navigation icon set so designers can pick from it.

        
Low
No Code Connect mapping yet. The Code Connect tools require a Dev/Full seat on an Organization plan. The Mantine NavLink mapping on this page is proposed.
