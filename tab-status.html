Tab Status node 852:10158 · a tissue built from Tab atom + Line atom

Tab Status is a tissue — the whole tab bar you drop into a page. It's assembled from two smaller pieces that don't ship on their own: a Tab atom (one clickable label) and a Line atom (the underline that carries the selected state in the line variant). Two variants ship: Segmented (pill track, atoms only) and Line (underline strip, each atom wrapped in a Line atom).

Anatomy

Both variants share the same three-tab payload: All (512) · Annotated (480) · Not annotated (32) with a folder glyph. Segmented: outer track fills bg/sunken, wraps atoms with 2px padding + 2px gap; the selected atom fills selected/bg and strokes accent/border. Line: outer track has a 1px border/subtle bottom, 4px gap, no fill; the selected Line atom paints a 2px accent/border bottom border. Tab atom padding differs by container — 12px in Segmented, 8px in Line — because the Line atom carries a slim outer padding of its own.

Usage rules

Choose Segmented when tabs sit inside a card or filter well — the sunken track visually contains them. Choose Line when tabs anchor a page or section header — the underline sits directly against the surface.

Exactly one Tab atom in the set carries the Selected state at any time. Zero-selected and multi-selected are both defects.

Never build a tab or an underline by hand. Every tab in a Tab Status is an instance of Tab atom; every underline slot in the Line variant is a Line atom.

Icon is optional on Tab atom (per its Icon boolean). Keep it consistent inside a single Tab Status — either all atoms show icons or none do.

Never use a Tab atom on its own as a "just one filter" chip. If a control has only one option, it is not tabs — reach for Tag (§08).

Do
  • Use Property=Segmented for in-card filter tabs
  • Use Property=Line for section headers on a surface
  • Bind fills to bg/sunken and selected/bg, borders to accent/border
  • Change label copy through the Section heading text property, not by detaching
Don't
  • Draw the underline as a raw 2px rectangle — use the Line atom
  • Hardcode #EAF4F0 for the selected pill — use selected/bg
  • Mix Segmented and Line variants in the same view
  • Leave zero or two Tab atoms in the Selected state at once
