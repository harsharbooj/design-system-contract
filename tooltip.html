Anatomy

Content pill: 24px tall, padding 4/8/4/8, radius 8, fill #ECEBE7 (--sunken), text 12px medium in #6B6862 (--text-2), default label "Tool tip". The Top variant stacks pill → 16×8 down-pointing arrow → anchor Button. Bottom reverses it (anchor → up-pointing arrow → pill). Default State renders the pill alone with no arrow — used when the tooltip is manually positioned.

Accessibility

Attach the tooltip via aria-describedby pointing at its id — never aria-label on the control itself (that replaces the accessible name).

Trigger on both hover and focus; dismiss on blur, mouseleave, or Escape. Content must be plain text, never interactive.

Usage rules

Attach to icon-only controls that need a name. Keep to 1–4 words.

Never put an action, link, or form inside a tooltip. If the content is interactive, it belongs in a Popover, not a Tooltip.

Do
  • Name an icon-only Button with 1–4 words
  • Choose Top/Bottom by which side has space
  • Trigger on hover and focus
Don't
  • Put a link, button, or form control inside
  • Use a tooltip for critical info a mouse user might miss
  • Wrap a long sentence in a tooltip — use Popover
