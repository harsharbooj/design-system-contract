Usage rules

Place icons by swapping the Placeholder instance with a real icon component. Never draw an icon directly on a screen.

Default to 20px (icon-md). Drop to 16 only in dense rows; go to 24 only for empty states and eyebrows.

Icon color is an icon/* token that matches the adjacent text's emphasis — icon/secondary beside text/secondary, icon/on-solid on a filled button.

A standalone icon action uses the Icon button set and must carry an aria-label; an icon beside a label is decorative (aria-hidden).

Rename the 27 icons still called Frame before agents rely on the set — an icon must be addressable by intent (Search, Delete, Filter). Also resolve the two components both named stop, and prune the ~14 icons that don't map to any OCR flow (see callout above).

Do
  • Swap Placeholder → a named icon component
  • Size icons from size/icon-*; keep 20 as default
  • Tie icon color to the neighbouring text/* emphasis
  • Give icon-only buttons an accessible name
Don't
  • Draw a one-off vector on the canvas
  • Scale an icon to an arbitrary size like 18 or 22
  • Leave icon fills on a raw primitive
  • Ship icon buttons without a label
