Action Modal "Fab Modal" in Figma · node 842:5021

A contextual dropdown menu triggered by a three-dot icon button. Shows three actions: Rename Version, Duplicate Version, and Delete Version (destructive). The Delete row escalates to a confirmation dialog that follows the same responsive contract.

Playground

click the three-dot button to open the menu · click Delete to open the confirmation dialog · Escape or click outside to dismiss

Delete this version?

This will permanently remove the selected capture version. This action cannot be undone.

Anatomy

Trigger: 38×38 Icon Button with the three-dot glyph. Menu: 197px wide, padding 12/16, 12px item gap, radius 4, 1px border/default, box-shadow. Each item is a horizontal row: icon (16) + label (14 medium). Divider (border/subtle, 1px) between rows. Confirmation dialog: max-width min(560px, calc(100vw - 32px)), padding 24, header + body + footer stacked, overlay z-index: 100 covering the viewport.

Accessibility

Trigger has aria-haspopup="menu"; aria-expanded toggles on open/close. Menu is role="menu", rows are role="menuitem".

Confirmation dialog uses role="dialog" + aria-modal="true" + aria-labelledby pointing at the title.

Dismiss on: click-outside, Escape, item selection. On Escape, return focus to the trigger.

Usage rules

Only Delete Version uses destructive tokens.

Menu width is fixed at 197px. The confirmation dialog is fluid to min(560px, 100vw - 32px).

Do
  • Trigger is the Icon Button (§10) Primary variant
  • Escalate destructive actions to a confirmation dialog
  • Dismiss on click-outside and Escape
Don't
  • Color Rename/Duplicate red
  • Let the menu width grow past 197px
  • Skip the confirmation on Delete

Findings from this pass
