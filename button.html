Accessibility

      

        
Render a native <button>. Loading sets aria-busy="true" and keeps the button in the tab order but inert; Disabled uses :disabled / aria-disabled.

        
Icons flanking a label are decorative — mark them aria-hidden="true". An icon-only action must instead use the Icon button set and carry an aria-label.

        
Focus is keyboard-visible via focus/ring (#10735F / #3C9081). Gap: the component set has no Focus variant yet — wire :focus-visible to the ring token in code until it's added in Figma.

      


      
Usage rules

      

        
Map Type to Mantine exactly: Primary=filled brand, Secondary=default, Tertiary=subtle, Danger=filled red. Never restyle a Secondary to imitate a Primary.

        
One Primary per view. Danger is reserved for destructive, irreversible actions — never for ordinary confirms.

        
Medium (36px) is the default; Small (28px) is for dense toolbars and table rows. Don't invent intermediate heights.

        
Loading keeps the label and swaps icons for the spinner — never collapse to a bare spinner (it shifts layout and drops the action name).

        
Compose from the Button New component and its props — never rebuild a button from a styled div or hardcode a fill.

Changelog — consistency pass
applied to Button New in Figma on 2026-09-08 · 9 fixes across 30 variant edits

      

        
Fixed
Danger · Disabled raw hex. Both sizes filled with an unbound #CE5C54 → rebound to bg/sunken + text/disabled, matching every other disabled Type.

        
Fixed
Primary · Loading label token. Bound to action/destructive/fg → corrected to action/primary/fg (Medium + Small).

        
Fixed
Danger · Hover (Medium) had no hover color (action/destructive/bg = Default) → rebound to action/destructive/bg-hover.

        
Fixed
Primary · Hover used the pressed token. action/primary/bg-pressed → action/primary/bg-hover (both sizes); hover/pressed no longer collapsed.

        
Fixed
Tertiary · Default / Hover inverted. Default carried a grey bg-pressed fill → made transparent (true ghost); Hover stays action/secondary/bg-hover.

        
Fixed
Small · Tertiary padding. Used 8px pad + 8 gap, breaking the Small 4/4 rule → reset to space/4 across all four Small Tertiary variants.

        
Fixed
Medium · Primary Hover asymmetric padding (8/9) → normalized to 8/8.

        
Fixed
Secondary · Disabled inconsistency across sizes (Medium bg-hover, Small bg/sunken+subtle border) → unified to bg/sunken + text/disabled, no border. Small · Secondary Hover label text/primary → action/secondary/fg.

        
Open
No Focus variant. Not auto-added (it changes the 32-variant matrix). Recommend adding a State=Focus row bound to focus/ring; wired via :focus-visible in code meanwhile.

      

      
These are edits to the Button New component's variants in Figma (fills, label bindings, padding/gap) — the underlying variable definitions were already correct, so no primitive or semantic values changed; only the component's bindings were corrected to use them consistently.
