05 Usage Patterns

Usage patterns

How the tokens actually assemble, read straight off the VD Main — Trained and Projects screens. Each recipe lists the real bound tokens. Patterns marked no component are built from raw frames today and are the first candidates for promotion into the library.

P1

Surface card

The base container for metric tiles, the Description panel and Labels-used. Surface fill, default border, medium radius, comfortable padding. There is no Card component — every screen rebuilds this from a frame.

P2

Metric / KPI card

The four performance tiles. An uppercase eyebrow, a large mono figure, and a signed delta badge in status color. Note the 18px vertical padding — off-scale, flagged in §03.

Button — primary & secondary

Actions in the page header (Retrain, Manual test). Primary is a brand fill; secondary is a bordered surface. Both carry a 20px leading icon and the Button text style. Button component exists (32 variants).
