09 Components · Switch

Switch Switch · 4 variants · node 40:614

A binary on/off toggle for a setting that takes effect immediately — dark mode, notifications, feature flags. A single variant axis, State, resolves to 4 published variants (Off, On, Disabled off, Disabled on). The track is 36×20, the thumb sits at one end via padding (2/20/2/2 for Off, 2/2/2/20 for On — no translate). The whole component is pill-shaped (radius/full). Off uses a flat text/tertiary gray track (#928E87); On uses accent/solid (#045646). Both Disabled variants share the same flat #BCB8B1 track — the two disabled states are distinguished by thumb position only, not track colour.

Disabled off and Disabled on BOTH fill with a flat #BCB8B1 (border/strong) — the two disabled variants share the same track colour; only the thumb position differs.

Accessibility

      

        
Render a native <input type="checkbox" role="switch"> (Mantine's Switch already does). The visible track/thumb is a styled sibling; never a bare <div onClick>.

        
Pair every switch with a visible label via <label for=""> — or the label prop on Mantine's Switch. A switch without a label is a defect: state without a name is meaningless.

        
The switch's state is aria-checked (handled by the native input). Do not add a redundant "On" / "Off" text label beside a colored track — the position and colour already convey it; a text state duplicates without adding meaning.

        
Focus binds to focus/ring at 2px, offset 2px. Gap: no Focus variant in Figma — wire via :focus-visible in code until it lands.

        
The action a switch triggers must be immediate and reversible. A switch is not a Save button — if the setting needs confirmation, use a checkbox with an explicit submit, not a switch.

      


      
Usage rules

      

        
Use Switch for settings that take effect immediately (dark mode, notifications, feature flags). Use Checkbox for form choices that submit later. This is the whole reason both components exist — never substitute one for the other.

        
Compose from the Switch component, one instance per setting, aligned to the right of its label row. Never rebuild the pill from a styled div or hardcode the accent hex.

        
State always maps 1-to-1 to Mantine's checked and disabled. Never encode "on" via a class name or a colour override — the check state is the source of truth.

        
A disabled switch keeps whatever value it had — Disabled on for a locked-on setting, Disabled off for a locked-off one. Never render a disabled switch in a state that misrepresents the underlying value.

        
Only one size ships — 36×20. Do not stretch, shrink, or introduce a "small switch" without adding a proper variant to the Figma component set first.

Findings from this pass
no Figma edits made — surface for review before a consistency pass

      

        
Clean
Component set is complete for the axis it commits to. Off / On / Disabled off / Disabled on cover every meaningful combination of checked × disabled. No missing entries in the matrix.

        
Clean
Spacing and radius are on-scale. Thumb inset binds to space/2, thumb size to size/icon-sm (16), track corner to radius/full, elevation to elevation/1. Only the track's own 36×20 dimensions are un-tokened — see next.

        
Found
Track dimensions have no named token. 36×20 is off the size/control-* scale (28/36/44). Options: add size/switch (36) + size/switch-h (20), or accept them as component-intrinsic constants and document them here (this file does the latter for now).

        
Found
No Focus, Hover, or Loading state. Switch has fewer live states than Button — Focus is the important one; wire it via :focus-visible until an explicit variant is added.

        
Found
Thumb fill is a raw #FFFFFF in both modes on Off/On. Intentional — the thumb has to read on both track colours — but worth capturing as a named token (switch/thumb) so future edits are one place, not four. On the two Disabled variants the thumb itself desaturates and drops its shadow — this pass's first draft mistakenly left the thumb pure white on Disabled on, which is why it read as "still On" rather than clearly inert; corrected here.

        
Found
State names use two conventions. Off / On are title-cased words; Disabled off / Disabled on use a space and lower-case second word. Consider unifying (e.g. Off, On, Disabled/Off, Disabled/On) so an agent can parse the axis as Disabled × Checked instead of a flat 4-way enum.
